# qualitat_aire_centres_educatius
Pràctica final de l'assignatura Visualització de Dades. En aquest projecte es pretén crear una visualització sobre els nivells de contaminació atmosfèrica en l’entorn dels centres educatius de Catalunya, mitjançant l’estimació de l’exposició a contaminants a partir de dades de qualitat de l’aire i la seva proximitat geogràfica.
